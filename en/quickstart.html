Get started

The goal is a first connection in a few minutes. You need a Windows PC, an iPad or iPhone, and a network they share (or Tailscale).

Invited to the beta? Try the beta has a plain-language, step-by-step guide.

  1. Install the Host on Windows

    Run Apobri-Setup-x.y.z.exe. The installer follows your Windows language (English or Traditional Chinese) and shows a privacy summary. You can choose start at sign-in (on by default) and firewall rules for the home network and Tailscale (on by default; one administrator prompt, which you can decline, but then the iPad may not reach the PC).

  2. Open the pairing page

    The last installer page starts Apobri and opens the pairing page by default. Later, use the Start menu entry “Apobri pairing page”. The page is visible only on this PC. It shows a QR code, the PC’s addresses (Tailscale first, then local network) and an 8-digit pairing code.

  3. Open Apobri on the iPad and pair

    The first launch asks for Local Network access; allow it, or the app cannot find your PC. Then pick one:

    • Scan the QR code: tap Scan QR and allow the camera (used only to read this QR code).
    • Nearby computers: PCs on the same local network are listed; tap one to start pairing without typing an address.
    • Type it in: enter the address and pairing code from the pairing page.

  4. First connection: tap Allow to trust the device

    After you enter the pairing code or scan the QR code, the iPad shows the Windows desktop; you do not need to press anything on the PC first. Once connected, the app asks “Trust this iPad?” Tap Allow (or press Allow on the PC’s pairing page instead). A trusted iPad reconnects later without a code. When a phone or iPad approves itself, the PC shows a notification. If it was not you, open the Apobri icon in the taskbar > “Paired devices” and remove it.

Use it away from home (Tailscale)

Apobri has no cloud server of its own: the screen goes straight between your devices. To reach your PC from another network, put the PC and your iPhone or iPad on the same private network that belongs to you, with the free Tailscale. You set it up once, in about five minutes; after that Apobri finds the way by itself.

  1. Install Tailscale on the PC and sign in

    On the PC, open tailscale.com/download/windows, install it and sign in with a Google, Microsoft, Apple or GitHub account (free for personal use). We recommend turning on “Run unattended” in the menu of the Tailscale icon on the taskbar, so the PC stays reachable after a restart, before anyone signs in to Windows.

  2. Restart the PC only if needed

    Usually not needed: newer Host versions pick up new network addresses automatically. Only an older Host (which uses the addresses that exist when it starts) needs one restart if Tailscale was installed later. The menu of the Apobri icon on the taskbar shows where you are; when it says “Away from home: ready” this step is done.

  3. Install Tailscale on the iPhone or iPad with the same account

    Get Tailscale from the App Store, sign in with the same account as on the PC, allow it to add a VPN configuration, and turn it on.

  4. Connect with Apobri once at home

    While you are on the same network as the PC, connect with Apobri once (and press Allow to make it a trusted device). Apobri remembers the PC’s Tailscale address. Away from home, when the home address does not answer, Apobri switches to Tailscale by itself; there is nothing to type.

Tailscale is a separate company’s service, not part of Apobri; its own terms and privacy policy apply. Apobri cannot see your Tailscale account. If the app says the connection goes through a relay, see this answer.

Troubleshooting

The iPad cannot find or reach my PC
  • Same network? The iPad and the PC must be on the same local network. If the router has “AP isolation” or “client isolation” on, devices cannot reach each other.
  • Local Network permission? In iPad Settings, open Apobri and make sure Local Network is on.
  • Is the PC awake and the Host running? Open the pairing page from the Start menu again (it waits up to 20 seconds). If it does not open, the Host is not running.
  • Firewall. If you did not tick the firewall option during setup, Windows Firewall may block the connection. Run the installer again and tick it.
  • Away from home. There is no cloud relay, so use Tailscale: follow the four steps in Use it away from home once.
  • “Nearby computers” is empty. You may be on a different subnet, or discovery was turned off in the PC’s config.json ("Discovery": false). Use the QR code or type the address.
Connected, but the picture is black
  • While the PC is locked, or shows the sign-in screen, a UAC prompt or the Ctrl+Alt+Del screen, Windows does not allow screen capture. The app shows an explanation instead of video, and recovers by itself after you unlock the PC.
  • If the Host starts but there is no video, the video encoder (ffmpeg) may be missing. The Host log then shows exit code 2 and the Host retries every 2 minutes.
  • Still black: create a diagnostics bundle and send it to us.
The PC went to sleep: how do I wake it? (Wake-on-LAN)

A sleeping PC cannot be connected to. After you connect, the Host gives the app the details of the PC’s physical network adapters so a Wake-on-LAN “magic packet” can be sent while the PC sleeps. Please know the limits:

  • It works only on the same local network. A magic packet is a LAN broadcast. It cannot wake the PC over Tailscale, mobile data or the Internet, and AP isolation on the router blocks it too.
  • Apobri never changes your power or adapter settings. You set them up in Windows:
    1. Device Manager > Network adapters > your adapter > Properties > Advanced: set “Wake on Magic Packet” to Enabled.
    2. Power Management tab: tick “Allow this device to wake the computer” and “Only allow a magic packet to wake the computer”.
    3. Only for waking from a full shutdown: enable Wake on LAN in BIOS/UEFI and turn off Windows Fast Startup. Waking from sleep usually does not need these.
  • Prefer a wired connection. Wake over Wi-Fi is supported by only a few laptops and drivers.
  • The Host includes a read-only checker, scripts\check-wol.ps1. It changes nothing, needs no administrator rights, and explains in plain words what is and is not set up.

Waking a real PC from sleep with a real iPad has not been fully verified yet, so treat wake-up as hardware-dependent.

Other: pairing keeps waiting / remove a device
  • Pairing keeps waiting: check that the pairing code is right, or scan the QR code on the PC instead. If the PC is locked, unlock it first. Otherwise start pairing again on the iPad.
  • A lost or retired iPad: Apobri icon in the taskbar > “Paired devices” > remove; or run AppleBridge.Host.exe --revoke all to revoke every device (the Host’s program file still uses the old name AppleBridge).
