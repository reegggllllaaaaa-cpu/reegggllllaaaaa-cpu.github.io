ffmpeg

The Apobri Host neither contains nor links the ffmpeg libraries. It starts ffmpeg.exe as a separate program, exchanges video data with it through pipes, and uses it as the video encoder. ffmpeg is used by the Host on the user’s PC.

The installer ships an LGPL build of ffmpeg (BtbN FFmpeg-Builds, win64-lgpl, version n9.0.2-28-g669f5ab083, built without --enable-gpl and --enable-nonfree), licensed under the GNU LGPL version 3 or later. The license texts, build configuration, source locations (FFmpeg source, build scripts) and a written offer for the source code are in the licenses\ffmpeg folder of the installation. You may replace ffmpeg.exe with your own build.

iPad / iPhone app

The iPad app uses a WebRTC library (a prebuilt package via Swift Package Manager, under a BSD-style license). It runs on your device and does not send your data to any third party.

Software that is used but not shipped

  • Tailscale: if the Host finds Tailscale installed on the PC it queries its status read-only. Tailscale is not part of Apobri; you install it yourself.
