Privacy policy

Last revised: 2026-10-17. Applies to the Apobri iPad/iPhone app and the Apobri Windows Host.

The short version

  • Apobri collects none of your data. There is no account, telemetry, analytics, crash upload or advertising, and no tracking. The developer never receives your screen, input, files or device information.
  • The screen, input, clipboard text and files go only to devices you paired, over your home network, Tailscale or another connection you set up yourself. There is no Apobri cloud or relay server.
  • The Windows Host itself does not open Internet connections. The one exception is the Apobri service’s update check, which only asks GitHub whether a new Host version exists and sends nothing about you.
  • Everything is stored on your own devices, and you can revoke devices or delete the data at any time.

What we collect

Nothing. The iPad app’s Privacy Manifest declares: no tracking, no tracking domains, no collected data types.

How data travels

Your iPad connects directly to your Windows PC. Video, input and the data channels use WebRTC with DTLS encryption. The Host uses no STUN or TURN server when connecting, so no third party learns your address.

One thing to state plainly: the signaling that sets up the connection currently uses an unencrypted HTTP port on your local network (default 8765). It includes the challenge-response used when logging in with a pairing code (the code itself is not sent in the clear). On networks you do not trust, use Tailscale. The Host’s HTTPS port (8766) uses a self-signed certificate whose fingerprint the app pins during QR pairing.

Toss and nearby direct links: what you put into Toss is synced between the devices you paired yourself (the PC, iPhone, iPad). Between a device and the PC it uses the same authenticated connection as above; when two Apple devices are near each other they connect directly over the local network or peer-to-peer Wi‑Fi (AWDL), encrypted with TLS (the keys come from a space key that only your devices hold). Nothing passes through any Apobri server. Toss keeps only what you explicitly put into it; ordinary copy and paste is not recorded. Note: after you remove a device it receives nothing new, but content already synced to that device cannot be taken back.

The Host listens only on private addresses: this PC, your local network (10.x, 172.16–31.x, 192.168.x) and Tailscale (100.64.x–100.127.x). The pairing page and device management accept requests only from the PC itself.

Automatic update check (Windows)

When the Apobri service (which keeps the Host up to date) is installed, it asks GitHub over HTTPS (api.github.com and GitHub’s download servers) for the newest Apobri Host release of one public repository every 6 hours, and when you press “Check for updates” / “Update” in the app. The request carries nothing about you or your PC besides what any web request carries (your IP address and a User-Agent: ApobriUpdater/1 header). A downloaded package is installed only if its signature verifies with the Apobri key built into the service. GitHub is an independent third-party service with its own privacy policy.

In-app purchases

The free trial and the unlock in the iPad/iPhone app are Apple in-app purchases. Apple handles payment and your Apple ID; we never receive your name, email or payment details. The app only asks the App Store whether this device’s Apple ID owns the trial or the unlock (and when the trial started).

What the iPad/iPhone app stores

  • Keychain: this device’s pairing key and pairing credentials.
  • App-local settings: the names and addresses of saved PCs, and connection and input preferences.
  • Files you receive are kept inside the app and in the Files app; they go to your Photos library only if you turn on “Save received photos & videos to Photos”.
  • Toss: the list of items in Toss, their thumbnails and the content you opened are cached in the app’s shared container (App Group). The Toss space key is kept in the Keychain for this device only; it is not synced to iCloud or included in backups.

This data does not leave your device, except what you yourself send to your PC during a connection. The Screen Broadcast extension sends the screen and sound of a broadcast you start yourself directly to the PC address you entered; it stores nothing and uses no server.

What the Windows Host stores

Everything lives under %APPDATA%\AppleBridge in your Windows profile (the folder name keeps the old product name), readable by default only by your Windows account.

Screen content is never written to disk: frames go from the GPU to the encoder to the network. The Host also sets the Windows clipboard when you ask it to. Apobri sends none of this anywhere.

System sound (whatever the PC is playing, possibly private) is captured only during an authenticated WebRTC connection and only while the iPad's Sound switch is on, and travels over the same encrypted connection to that iPad; it is not recorded or written to disk, and in every other case the audio device is not opened at all. Turn it off in the iPad settings, or set "Audio": false in the Host config.

For the “Nearby computers” feature the Host announces itself on your local network with mDNS (_apobri._tcp): the computer name, private LAN IPv4 addresses, ports, the certificate fingerprint (public information), whether pairing is allowed, and a random host id. The announcement never leaves the local network and never contains the pairing code, keys, user name, file names or window titles. People on the same network can learn that this PC runs Apobri, but cannot connect: a new device still needs the pairing code or QR code shown on the PC. You can turn it off with "Discovery": false in config.json.

For Toss’s nearby direct links, the iPhone and iPad also announce the Bonjour service _apobri-toss._tcp on the local network and over peer-to-peer Wi‑Fi (AWDL). The announced name is a hash derived from the space key that changes every day; it contains no device name, user name or any fixed identifier. Without your space key nobody can tell whose device it is or connect to it.

Local helper programs the Host runs: ffmpeg.exe (video encoding), powershell (notifications), and, only if Tailscale is installed, tailscale status --json (read-only). None of them is told to contact the Internet.

Revoking and deleting

  • Revoke one device: pairing page on the PC > device list, or AppleBridge.Host.exe --revoke <id-prefix>. Revoke all: AppleBridge.Host.exe --revoke all. Connected sessions are dropped immediately. A revoked device gets no new Toss content (the PC hands a new space key to the devices left), but content already synced to it cannot be taken back.
  • Delete all Host data: answer yes to deleting settings, devices and logs when uninstalling, or delete %APPDATA%\AppleBridge yourself.
  • Delete app data: delete the Apobri app from your iPad; its Keychain items and local data are removed with it.

Third-party components

Apobri uses open-source components (for example SIPSorcery, QRCoder and Vortice in the Host, and a WebRTC library in the iPad app) and calls ffmpeg as a video encoder. They all run on your devices and do not send your data to their authors or any third party. See Licenses and third-party notices for the list and licenses. Tailscale, if you choose to use it, is a separate third-party service with its own privacy policy.

Children’s privacy

Apobri is not directed at children and collects no personal data from anyone, including children.

Changes to this policy

If the policy changes materially, we will update this page and the revision date above.
