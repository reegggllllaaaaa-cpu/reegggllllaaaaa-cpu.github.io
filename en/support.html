FAQ

Do I need an account?

No. Apobri has no account system.

Can I use it away from home?

Yes, with Tailscale: install it on the PC and the iPad and sign in to the same account. Apobri itself has no cloud relay and uses no STUN/TURN, so only a local network or a private network you set up yourself (such as Tailscale) is supported. Tailscale is not part of Apobri; you install it yourself and its own terms and privacy policy apply.

The app says “Connected through a relay: higher latency”. What does it mean?

Tailscale could not open a direct path between the PC and your iPad or iPhone, so the traffic goes through one of Tailscale’s relay servers (DERP). A relay has less bandwidth and a longer round trip (often 60–150 ms). When Apobri detects a relay it keeps every picture small enough for the relay and adds the fine detail back once scrolling stops; resolution and frame rate stay the same, so it remains smooth to use, but latency is always higher than on a direct path.

To get a direct path you can try (none of this is required):

  • Turn on UPnP or NAT-PMP/PCP on your home router (often under “Advanced”, “NAT” or “Port forwarding”). Tailscale then usually sets up a direct path by itself.
  • Try another network on the iPhone or iPad: some company, school, hotel and mobile networks block UDP, which leaves only the relay.
  • On the PC, run tailscale netcheck and check that “UDP” is true and “PortMapping” lists something; in tailscale status, the line of the other device says relay "xxx" while relayed and direct when direct.
Why tap Allow to make a device trusted?

A new device connects with the pairing code or QR code shown on the PC; nobody without the code can connect. Allow is an extra step: the device becomes a trusted device, its key is stored (encrypted) on the PC, you do not need the code again, and the share sheet and clipboard shortcuts work in the background. For safety, only the connection of the person actually using this PC can approve; it is valid for 60 seconds, at most 3 times per hour per PC, and cannot be approved while the PC is locked or someone is at the PC.

Is there sound?

Yes, but it is new and not yet verified on a real iPad: the Host sends Windows system sound to the iPad as Opus, over the WebRTC transport only (the WebSocket / HEVC transport has no sound). It captures only while an iPad is connected and its Sound switch is on; local playback is unaffected. Latency and audio/video sync have not been measured.

Which devices are supported?

Clients are iPad and iPhone (iPadOS/iOS 17.0 or later); the controlled computer is Windows 10 or 11. There is no Mac, Android or Linux version.

How do I revoke a device?

On the PC, open the pairing page and revoke it in the device list. Or use the command line: AppleBridge.Host.exe --devices to list, AppleBridge.Host.exe --revoke <id-prefix> for one device, --revoke all for all. Connected sessions are dropped immediately.

How do I turn off the “nearby computers” announcement?

Add "Discovery": false to %APPDATA%\AppleBridge\config.json and restart the Host. The iPad then needs the QR code or the address to pair.

Why do program files and folders say AppleBridge?

AppleBridge was Apobri’s earlier name. The Host’s program file name and data folder (for example %APPDATA%\AppleBridge) still use it.

Diagnostics bundle: create and send

A diagnostics bundle is a zip with the information needed to investigate a problem. A script on your PC builds it, nothing is uploaded, and no administrator rights are needed. You decide whether to send it and to whom.

How to create it

  1. Start menu > Apobri folder > “Collect Apobri diagnostics”. (Or run collect-diagnostics.ps1 from the scripts folder of the Host installation.)
  2. When it finishes, Explorer opens with the file selected: Documents\Apobri-diagnostics\apobri-diagnostics-<time>.zip.
  3. Attach the zip to an email to us. Please look inside first.

What it contains

  • summary.txt: Host version and path, Windows build and language, RAM, GPU and driver, .NET runtimes, ffmpeg version and available hardware encoders, scheduled-task and firewall-rule status, which programs listen on the Host ports, whether Tailscale is installed, network adapters, the settings of config.json (without the pairing code and inbox token), and paired device names, platform and last-seen time.
  • host.log.tail.txt, host.err.log.tail.txt: the last 2000 log lines, redacted.
  • capabilities.json: the Host’s probe of this PC (encoders, GPU, display modes, measured throughput).
  • negotiate.recent.txt: what quality recent connections were given, and why.
  • README-redaction.txt: counts of what was removed.

What it does not contain (removed, or never read)

  • The pairing code, inbox token and device keys; devices.json is never read.
  • Long hexadecimal strings (keys or tokens), values such as token=, key=, code=, secret URL query parameters and base64 blobs.
  • Your Windows user name and the PC name (masked in paths).
  • Screen content (the Host never writes frames to disk).
Note: IP addresses are kept by default (they are needed to debug LAN and Tailscale problems). Run the script with -RedactIps to mask them as a.b.x.x. Device names you typed yourself (such as “Sam’s iPad”) are kept as well, so check before sending. If any known secret value is still present after redaction, the script stops without writing the zip.

Known limitations

We would rather tell you up front. Limits of the current version:

  • Not yet fully verified on real devices. Development happened mostly on Windows; behaviour of the native iPad app on real networks is still being verified, which is why this site gives no performance numbers.
  • One screen is streamed at a time. The Host lists the connected screens and you pick which one to stream; you cannot view several at once.
  • Extending is opt-in. By default the iPad shows the content of an existing screen of the PC. To make the iPad an additional Windows monitor, choose Settings > Second screen > Extend in the app (iPad only; the Host on the PC must be a version that supports it).
  • Sound is not yet verified on hardware and is WebRTC-only. Windows system sound is sent to the iPad as Opus but has not been heard on a real iPad; latency and audio/video sync are unmeasured, and the WebSocket / HEVC transport has no sound.
  • Ctrl+Alt+Del cannot be sent from the iPad. Windows allows neither capture nor input on the secure desktop (lock screen, sign-in screen, UAC prompts). Apobri can only show a notice such as “PC is locked”; you must act on the PC. Windows running as administrator cannot be controlled either.
  • Clipboard sync is plain text only (no images or files yet). Files use the separate file-transfer feature; whole folders are not supported.
  • On a local network, the connection setup is plain HTTP. Video and the input and data channels are encrypted by WebRTC (DTLS), but the signaling (the handshake that sets up the connection, including the challenge-response when logging in with a pairing code) uses an unencrypted HTTP port (default 8765) on your LAN. Other people on the same network could in principle observe that handshake. On networks you do not trust (public Wi-Fi, offices), connect through Tailscale instead. Moving to TLS with certificate pinning is planned.
  • The pairing code is stored as plain text in config.json (readable only by the current Windows user). Other programs running as the same Windows user can read it.
  • No direct connection over the Internet: there is no STUN/TURN; use Tailscale for remote use.
  • Wake-on-LAN works only on the same local network and is not yet fully verified on real hardware; see Get started.
