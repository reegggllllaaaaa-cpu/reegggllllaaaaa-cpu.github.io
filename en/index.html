Use your Windows PC from your iPad.
Direct connection, no cloud.

Apobri is an iPad/iPhone app plus a Host for Windows. Over your home network or Tailscale, the two devices exchange the screen and your input directly. There is no account and no relay server.

Download and install Get started

Three things that matter

Built for low latency

The Host uses GPU hardware encoding (Intel QSV, NVIDIA NVENC, AMD AMF) and real-time WebRTC transport. Mouse and keyboard use a dedicated input channel.

We do not publish latency figures here: they will be written only after measuring on real iPads and real networks.

Your iPad as the Windows screen and input

See the whole Windows desktop and control it with touch, mouse, trackpad or a hardware keyboard. Clipboard text and files go both ways.

By default this is remote control of the PC’s existing screen; an iPad can also extend Windows as an extra display (Settings > Second screen > Extend). See known limitations.

Privacy: a direct connection, no cloud

The screen and your input go only to devices you paired. The Host has no telemetry, analytics or ads, and opens no outbound Internet connection of its own (the auto-update service only asks GitHub for new versions; see the privacy policy). A new device must be approved with Allow on the PC.

How it works

After you install the Host on your PC it shows a pairing page (QR code and pairing code). On the iPad you scan the code or pick the PC under “Nearby computers”, then press Allow on the PC. After that the same iPad does not need the code again. Away from home, sign in to the same Tailscale network on both devices.

Download and install

iPad / iPhone app

Get Apobri from the App Store. Requires iPadOS or iOS 17.0 or later.

App Store (coming soon)

Windows Host

Run the installer on the Windows PC you want to control (Windows 10 version 2004 or later, 64-bit). It asks for administrator permission once and installs the Host, the notification-area icon, the background service (lock screen, virtual display, automatic updates) and firewall rules (home networks and Tailscale only). When it finishes, Apobri starts and the pairing page with a QR code opens: scan it with Apobri on your iPad or iPhone.

Download the Windows installer

If you see “Windows protected your PC”: the installer is not code-signed yet, so Microsoft Defender SmartScreen shows this blue window. Click More info, check that the file name is Apobri-Setup-…exe, then click Run anyway. A SHA-256 checksum is published next to the download (check it with PowerShell Get-FileHash).

To uninstall: Windows Settings → Apps → Installed apps → Apobri → Uninstall. This removes the service, the virtual display driver and the firewall rules, and asks whether to keep your paired devices and settings.

System requirements

Windows PCWindows 10 or Windows 11. A GPU with hardware H.264 / HEVC encoding is required: Intel (QSV), NVIDIA (NVENC) or AMD (AMF) (almost every recent laptop and desktop has one). PCs without a hardware encoder (for example some virtual machines) cannot send the screen. The Host uses ffmpeg for video encoding; see Licenses.
iPad / iPhoneiPadOS 17.0 or iOS 17.0 or later. Local Network permission is needed on the first connection.
NetworkThe iPad and the PC on the same local network, or Tailscale installed and signed in on both. Other routes over the Internet are not supported (there is no STUN or TURN).
