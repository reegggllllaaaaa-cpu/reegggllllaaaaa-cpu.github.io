快速上手

目標是在幾分鐘內完成第一次連線。你需要：一台 Windows 電腦、一台 iPad 或 iPhone，以及它們共用的網路（或 Tailscale）。

  1. 在 Windows 安裝 Host

    執行 Apobri-Setup-x.y.z.exe。安裝程式會依 Windows 語言顯示英文或繁體中文，並說明隱私摘要。你可以選擇「登入 Windows 時自動啟動」（預設開啟）與「為家用網路及 Tailscale 開啟防火牆規則」（預設開啟，會要求一次系統管理員授權，可拒絕；拒絕後 iPad 可能連不到電腦）。

  2. 開啟配對頁

    完成頁面預設會啟動 Apobri 並開啟配對頁；之後也可以從開始功能表的「Apobri pairing page」開啟。配對頁只能在這台電腦上看到，內容有 QR Code、這台電腦的位址（Tailscale 優先，其次區域網路）與 8 位數配對碼。

  3. 在 iPad 開啟 Apobri 並配對

    第一次會詢問「區域網路」權限，請按允許，否則找不到電腦。接著擇一：

    • 掃描 QR Code：點「掃描 QR Code 配對」，允許相機（只用來掃這個 QR Code）。
    • 附近的電腦：同一個區域網路上的電腦會出現在清單，點一下就開始配對，不用輸入位址。
    • 手動輸入：輸入配對頁顯示的位址與配對碼。

  4. 在電腦按「允許」

    配對頁（或命令列視窗）會問你是否允許這個裝置。請只允許你認得的裝置。120 秒內沒有按，配對會取消，從 iPad 再試一次即可。

  5. 第一次連線

    按下允許後，iPad 就會顯示 Windows 桌面。往後同一台 iPad 重新連線不需要再輸入配對碼。要撤銷某台裝置，到配對頁的裝置清單移除。

常見問題排除

iPad 找不到我的電腦／連不上
  • 在同一個網路嗎？iPad 與電腦要在同一個區域網路（同一個 Wi-Fi 或同一個路由器）。路由器若開啟「AP 隔離」或「客戶端隔離」，裝置之間無法互相連線。
  • 允許了「區域網路」權限嗎？到 iPad「設定」找到 Apobri，確認「區域網路」已開啟。
  • 電腦醒著、Host 在執行嗎？從開始功能表再開一次配對頁（最多等 20 秒），打不開就是 Host 沒啟動。
  • 防火牆。安裝時若沒有勾選防火牆規則，Windows 防火牆可能擋住連線。可重新執行安裝程式並勾選該項。
  • 人在外面。Apobri 沒有雲端中繼。請在電腦與 iPad 都安裝 Tailscale 並登入同一個帳號；配對頁會列出電腦的 Tailscale 位址。
  • 「附近的電腦」是空的。可能是不同網段、或在電腦的 config.json 關閉了探索（"Discovery": false）。改用 QR Code 或手動輸入即可。
連上了但畫面是黑的
  • 電腦被鎖定，或正顯示登入畫面、UAC 提示、Ctrl+Alt+Del 畫面時，Windows 不允許擷取螢幕，App 會顯示說明而不是影像。解鎖電腦後會自動恢復。
  • Host 啟動後沒有影像，也可能是找不到影像編碼器（ffmpeg）。這時 Host 記錄檔會看到結束代碼 2，並每 2 分鐘重試一次。
  • 仍然黑屏：產生診斷包並回報給我們。
電腦睡眠了，怎麼喚醒？（Wake-on-LAN）

睡眠中的電腦無法被連線。Host 會在你連線後，把電腦實體網路卡的資訊提供給 App，以便電腦睡著時送出 Wake-on-LAN「魔術封包」。這有幾項限制，請先了解：

  • 只在同一個區域網路有效。魔術封包是區網廣播；經由 Tailscale、行動網路或外網都無法喚醒電腦。路由器的 AP 隔離也會擋住它。
  • Apobri 不會幫你改任何電源或網路卡設定。需要你自己在 Windows 設好：
    1. 裝置管理員 > 網路介面卡 > 你的網路卡 > 內容 > 進階：「喚醒魔術封包」設為啟用。
    2. 同一視窗的「電源管理」：勾選「允許這個裝置喚醒電腦」與「僅允許魔術封包喚醒電腦」。
    3. 從「關機」喚醒才需要：BIOS／UEFI 開啟 Wake on LAN，並關閉 Windows 的「快速啟動」。從「睡眠」喚醒通常不用。
  • 建議使用有線網路。Wi-Fi 的喚醒只有少數筆電與驅動程式支援。
  • Host 附有唯讀的檢查工具 scripts\check-wol.ps1：它只讀取、不修改任何設定，也不需要系統管理員權限，會列出各網路卡的狀態並用白話給建議。

目前尚未用真實電腦與 iPad 完整驗證「從睡眠喚醒」，喚醒功能請視為可能因硬體而異。

其他：一直停在等待配對／想撤銷裝置
  • 配對一直等待：沒有人在 120 秒內按「允許」。在配對頁按允許，或從 iPad 再發起一次。
  • 遺失或不再使用某台 iPad：配對頁 > 裝置清單 > 撤銷；或在命令列執行 AppleBridge.Host.exe --revoke all 撤銷全部裝置（Host 的程式檔名仍沿用舊稱 AppleBridge）。

Apobri：用 iPad 或 iPhone 操作 Windows 電腦。不蒐集資料，不經雲端。
