ffmpeg

Apobri Host 不內含也不連結 ffmpeg 的函式庫；它把 ffmpeg.exe 當成獨立的子程式啟動，透過管線交換影像資料，用它做影像編碼。ffmpeg 是由使用者端的 Host 使用的。

安裝程式隨附的是 LGPL 版 ffmpeg（BtbN FFmpeg-Builds 的 win64-lgpl 建置，版本 n9.0.2-28-g669f5ab083，未啟用 --enable-gpl 與 --enable-nonfree），授權為 GNU LGPL 第 3 版或更新版本。授權全文、建置設定、原始碼位置（FFmpeg 原始碼、建置腳本）與書面提供原始碼的承諾，都放在安裝資料夾的 licenses\ffmpeg。你可以把 ffmpeg.exe 換成自己的建置。

iPad／iPhone App

iPad App 使用 WebRTC 函式庫（透過 Swift Package Manager 的預先建置版本，採 BSD 風格授權）。它在你的裝置上執行，不會把你的資料送給第三方。
