隱私權政策

最後修訂：2026-10-17。適用範圍：Apobri iPad／iPhone App 與 Apobri Windows Host。

簡短版

  • Apobri 不蒐集你的任何資料。沒有帳號、遙測、使用分析、當機回報或廣告，也沒有任何追蹤。開發者不會收到你的畫面、輸入、檔案或裝置資訊。
  • 畫面、輸入、剪貼簿文字與檔案，只會傳給你配對過的裝置，經由你的家用網路、Tailscale 或你自己設定的連線。Apobri 沒有帳號，也沒有會看到你畫面的伺服器。只有在手機和電腦無法直接連線（例如你人在外面、又沒有使用 Tailscale）時，才會借用 Cloudflare 的轉接服務幫兩台裝置找到彼此，詳見資料如何傳送。
  • Windows Host 本身不會主動連上網際網路。唯一的例外是 Apobri 服務的自動更新檢查：只向 GitHub 查詢有沒有新版 Host，不送出任何關於你的資料。另一個例外是上面說的 Cloudflare 轉接服務，而且只有在無法直接連線時才會用到。
  • 所有資料都存在你自己的裝置上，你可以隨時撤銷裝置或刪除資料。

我們蒐集什麼

什麼都不蒐集。iPad App 的隱私資訊清單（Privacy Manifest）宣告：不追蹤、沒有追蹤網域、沒有蒐集任何資料類型。

資料如何傳送

你的 iPad 與 Windows 電腦直接連線。畫面、輸入與資料通道使用 WebRTC，並經 DTLS 加密。同一個網路或 Tailscale 上的連線，不會用到任何 STUN／TURN 伺服器，也沒有第三方得知你的位址。

無法直接連線時（在外面、沒有 Tailscale）：App 會改用 Cloudflare 提供的轉接服務（Cloudflare Workers）和公開的 STUN 伺服器（Cloudflare、Google），讓兩台裝置找到彼此並嘗試直接連線；兩邊的網路限制太嚴時，也可能經由 Cloudflare 的 TURN 中繼轉送畫面。這些服務看得到：這台電腦的識別碼（一組隨機編號，不含你的姓名）、你手機和電腦的網際網路位址（IP）、連線的時間與資料量。它們看不到你的畫面、輸入、檔案或剪貼簿內容：連線資料在你的手機和電腦之間以端對端加密傳送（只有已配對的兩台裝置有金鑰），畫面本身也有 DTLS 加密。Apobri 不會把這些紀錄存下來，也不需要帳號。你可以隨時在電腦上撤銷裝置；沒有配對過的裝置完全不會使用這個服務。

需要誠實說明的一點：新版 App 建立連線用的「信令」走 TLS（wss，Host 的 HTTPS 連接埠 8766，自簽憑證），App 會釘選憑證指紋。舊版 App 與網頁版（PWA）仍走未加密的 HTTP 連接埠（預設 8765），其中包含以配對碼登入時的挑戰回應（配對碼本身不會明文送出）。在不信任的網路上，請使用新版 App 或 Tailscale。

Toss（隨手丟）與近距離直連：你放進 Toss 的東西，會在你自己配對過的裝置（電腦、iPhone、iPad）之間同步。裝置與電腦之間走上面同一條已驗證的連線；兩台蘋果裝置在附近時，會在同一個區域網路或點對點 Wi‑Fi（AWDL）上直接連線，並以 TLS 加密（金鑰由只有你的裝置持有的空間金鑰導出）。全程不經過任何 Apobri 伺服器。Toss 只保存你明確放進去的東西；一般的複製貼上不會被記錄。注意：移除一台裝置後，它之後不會再收到新內容，但已經同步到那台裝置上的內容無法收回。

配對與直連：用 QR Code 配對時，QR Code 會帶著這台電腦的身分憑證指紋，App 在配對時會核對它，確認連到的是你面前這台電腦，而不是同一個網路上的別台。iPad／iPhone 與電腦在同一個 Wi‑Fi 時，會直接走區域網路連線，不會繞到網際網路或其他網路路徑。

傳檔沒有大小上限：從 iPad 傳到電腦的檔案不再限制大小，唯一的限制是電腦的磁碟剩餘空間。空間不夠時傳輸會中止、刪掉未完成的暫存檔，並告訴你原因。

Host 只在私人位址上監聽：本機、區域網路（10.x、172.16–31.x、192.168.x）與 Tailscale（100.64.x–100.127.x）。配對頁與裝置管理功能只接受來自這台電腦本機的請求。

自動更新檢查（Windows）

安裝了 Apobri 服務（負責自動更新 Host）時，服務每 6 小時、以及你在 App 裡按「檢查更新」／「更新」時，會以 HTTPS 向 GitHub（api.github.com 與 GitHub 的下載伺服器）查詢一個公開儲存庫的最新 Apobri Host 版本。請求裡除了任何網路請求都會帶的資訊（你的 IP 位址、User-Agent: ApobriUpdater/1）之外，不包含任何關於你或你電腦的資料。下載的更新套件必須通過服務內建的 Apobri 金鑰簽章驗證才會安裝。GitHub 是獨立的第三方服務，適用其自己的隱私政策。

App 內購買

iPad／iPhone App 的免費試用與解鎖都是 Apple 的 App 內購買，由 Apple 處理付款與 Apple ID；我們不會收到你的姓名、Email 或付款資料。App 只向 App Store 確認這台裝置的 Apple ID 是否擁有試用或解鎖項目（以及試用開始的時間）。

iPad／iPhone App 存了什麼

  • 鑰匙圈（Keychain）：這台裝置的配對金鑰與配對憑證。
  • App 本機設定：已儲存電腦的名稱與位址、連線與輸入偏好。
  • 收到的檔案存在 App 內與「檔案」App；只有在你開啟「將收到的照片與影片存到『照片』」選項時，才會存進「照片」。
  • Toss：放進 Toss 的項目清單、縮圖與你打開過的內容，快取在 App 的共用容器（App Group）內；Toss 的空間金鑰存在鑰匙圈，僅限這台裝置，不會同步到 iCloud 或寫進備份。

這些資料不會離開你的裝置，除非是你在連線中傳給你的電腦。「螢幕廣播」擴充只把你主動開始廣播的畫面與聲音直接送到你輸入的那台電腦，不存檔、不經過任何伺服器。

Windows Host 存了什麼

全部在你的 Windows 使用者設定檔下的 %APPDATA%\AppleBridge（資料夾名稱沿用舊稱），預設只有你的 Windows 帳號能讀取。

檔案內容保護
config.json設定、8 位數配對碼、供 iPhone 捷徑使用的 Inbox Token設定是純文字；配對碼與 Inbox Token 以 Windows DPAPI 加密（只有您這個 Windows 帳號能解）。檔案存取權限也限制為目前的 Windows 使用者
devices.json每台已配對裝置：編號、名稱、平台、建立與最後連線時間、驗證用資料驗證用資料以 Windows DPAPI（目前使用者範圍）加密；複製到別台電腦或別的使用者無法解開
host.pfx（及密碼檔）Host 自簽的 HTTPS 憑證與私鑰，第一次啟動時產生每次安裝隨機密碼，以 DPAPI 保護；檔案權限限制為目前使用者
host.log（與 host.log.1～host.log.4）、host.stdout.log、host.err.log操作記錄：連線時間、裝置名稱與編號、裝置的 IP 位址、編碼與網路統計純文字。host.log 每個檔案最多 10 MB，最多保留 5 個（含目前的），更舊的自動刪除；host.stdout.log 只留程式的原始輸出（超過 5 MB 換成 .old）。配對碼與 Inbox Token 不會寫入記錄檔；舊版曾寫入的，新版啟動時會自動把它們蓋成 *
tokens.json已配對裝置的存取憑證（token）與到期時間，讓電腦重新啟動或更新後，裝置不必重新取得憑證。只保存已配對裝置的；用配對碼登入取得的不會存檔內容以 Windows DPAPI（目前使用者範圍）加密；移除裝置時，它的憑證立即失效並從檔案刪除
tray.log系統匣圖示的運作記錄純文字，放在同一個資料夾
audio-local-mute.json只記錄「電腦喇叭目前是不是被 Apobri 暫時靜音」，讓當機或重新啟動後能把聲音還原。不含任何聲音內容純文字，沒有個人資料
display-snapshot.json、display-placement.json、mirror-window.json螢幕排列、各台 iPad 的位置，以及手機畫面鏡射視窗的位置與大小，用來在中斷後還原你的顯示設定純文字，沒有畫面內容
%LOCALAPPDATA%\Apobri\iconcache程式圖示的快取（小張 PNG 圖片）。你在 iPad 上看應用程式或視窗清單時，電腦會先把圖示存起來，下次就不必重新擷取；從中看得出這台電腦裝了哪些程式，但沒有螢幕內容。最多保留約 3000 張，超過時刪掉最舊的一般圖片檔，放在你的使用者資料夾內；可以直接刪除整個資料夾，需要時會重新產生
%ProgramData%\Apobri\service.log、helper.logApobri 背景服務與登入畫面輔助程式的運作記錄（啟動、更新檢查、顯示器狀態）。service.log 每個最多 5 MB、保留 5 份；helper.log 每個最多 5 MB、保留 4 份，超過就丟掉最舊的純文字；這是整台電腦共用的位置（不在你的使用者資料夾內），沿用 Windows 對該資料夾的預設權限。不含配對碼
Downloads\Apobri（舊版為 Downloads\AppleBridge，啟動時自動改名）你從 iPad 傳來或傳到 iPad 的檔案一般的下載資料夾權限
toss\Toss 的同步日誌與狀態：你放進 Toss 的項目（包括你放入的文字與網址）、項目名稱與縮圖、成員裝置的名稱，以及 Toss 的空間金鑰空間金鑰以 Windows DPAPI（目前使用者範圍）加密；其餘為純文字，放在你的使用者資料夾內，沿用 Windows 預設的使用者資料夾權限。整理日誌時，舊日誌會暫時留一份備份（ops.jsonl.bak，內容和日誌一樣）
Downloads\Apobri\.apobri-shelf\放進 Toss 的檔案與它們的各個版本，以及從 iPad 編輯檔案時暫時用的 .apobri-edit-… 暫存檔（存好或失敗後會刪掉）一般的下載資料夾權限

螢幕畫面不會被寫入磁碟：影格直接由 GPU 送到編碼器再送上網路。Host 也會依你的要求設定 Windows 剪貼簿內容。Apobri 不會把這些資料送到任何地方。

系統聲音（電腦正在播放的內容，可能含私密內容）只在已驗證的 WebRTC 連線期間、且 iPad 的「聲音」開關開著時才擷取，經同一條加密連線傳給該 iPad；不錄音、不寫檔，其他情況完全不開啟音訊裝置。iPad 確認正在播放時，電腦本機的喇叭會暫時靜音，斷線、關閉聲音或重新啟動後自動還原（AudioMutePcWhileConnected 設為 false 可關閉這個行為）。可在 iPad 設定關閉，或在 Host 設定檔設 "Audio": false。

Host 為了「附近的電腦」功能，會在區域網路上以 mDNS（_apobri._tcp）公告：電腦名稱、私人區網 IPv4 位址、連接埠、憑證指紋（公開資訊）、是否允許配對，以及一個隨機產生的主機識別碼。公告不離開區域網路，也不包含配對碼、金鑰、使用者名稱、檔名或視窗標題。同一個網路上的人可能知道「這台電腦有安裝 Apobri」，但仍然無法連線：新裝置必須有電腦上顯示的配對碼或 QR Code。你可以在 config.json 設 "Discovery": false 關閉。

Toss 的近距離直連另外由 iPhone／iPad 以 Bonjour 服務 _apobri-toss._tcp 在區域網路與點對點 Wi‑Fi（AWDL）上公告。公告的名稱是每天輪換、由空間金鑰算出的雜湊，不含裝置名稱、使用者名稱或任何固定識別碼；沒有你的空間金鑰的人看不出是誰，也無法連線。

Host 會執行的本機輔助程式：ffmpeg.exe（影像編碼）、powershell（顯示通知）、以及（只有已安裝 Tailscale 時）tailscale status --json（唯讀）。它們都不會被指示去連網際網路。

權限與用途

權限用途
區域網路在你的網路上找到並連線到你的 Windows 電腦（含「附近的電腦」，使用 Bonjour 服務 _apobri._tcp），並顯示與控制它；以及 Toss 在你自己的裝置之間近距離直連（Bonjour 服務 _apobri-toss._tcp）。只在你第一次開始連線（或按「尋找這個網路上的電腦」）時才會詢問；示範模式不需要。沒有此權限就無法連線。
相機只用來掃描 Host 配對頁上的 QR Code。不拍照、不錄影。
麥克風只有在你從系統廣播選單開始「螢幕廣播」並打開麥克風按鈕時，才把麥克風聲音送到你的電腦。其他情況不錄音。
照片（僅新增）只有在你開啟「將收到的照片與影片存到『照片』」時，才會把從電腦傳來的照片與影片存進「照片」。Apobri 不會讀取你的相簿。

撤銷與刪除

  • 撤銷一台裝置：工作列的 Apobri 圖示 >「已配對的裝置」，或 AppleBridge.Host.exe --revoke <編號開頭>。撤銷全部：AppleBridge.Host.exe --revoke all。已連線的工作階段立刻中斷。被撤銷的裝置不會再收到新的 Toss 內容（電腦會換一把新的空間金鑰給其餘裝置），但已經同步到它上面的內容無法收回。
  • 刪除所有 Host 資料：解除安裝時選擇一併刪除設定、裝置與記錄，或自行刪除 %APPDATA%\AppleBridge。
  • 刪除 App 資料：在 iPad 刪除 Apobri App，其鑰匙圈與本機資料也會隨之移除。

第三方元件

Apobri 使用開放原始碼元件（例如 Host 的 SIPSorcery、QRCoder、Vortice，iPad App 的 WebRTC 函式庫），並呼叫 ffmpeg 作為影像編碼器。它們都在你的裝置上執行，不會把你的資料送給它們的作者或任何第三方。清單與授權見授權與第三方聲明。Tailscale（若你自己選擇使用）是獨立的第三方服務，適用其自己的隱私政策。

兒童隱私

Apobri 不針對兒童，也不蒐集任何人的個人資料，包括兒童。

政策變更

若政策有實質變更，我們會更新本頁並修改上方的修訂日期。
