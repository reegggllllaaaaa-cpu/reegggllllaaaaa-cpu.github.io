用 iPad 操作你的 Windows 電腦，
直接連線，不經雲端。

Apobri 由 iPad／iPhone App 與安裝在 Windows 的 Host 組成。在家用網路或 Tailscale 上，兩個裝置之間直接傳送畫面與輸入，沒有帳號、沒有中繼伺服器。

下載與安裝 快速上手

三個重點

以低延遲為首要目標

Host 用 GPU 硬體編碼（Intel QSV、NVIDIA NVENC、AMD AMF），透過 WebRTC 即時傳送，滑鼠與鍵盤另走專用的輸入通道。

我們不在這裡公布延遲數字：數字要在真實的 iPad 與網路上量測後才會寫。

iPad 變成 Windows 的畫面與輸入

看到完整的 Windows 桌面，用觸控、滑鼠、觸控板或實體鍵盤操作；剪貼簿文字與檔案可雙向傳送。

預設是遠端操作電腦現有的螢幕；iPad 也可以在設定的「第二螢幕」選「延伸」，當 Windows 多出來的螢幕。見已知限制。

隱私：不經雲端的直連

畫面與輸入只傳給你配對過的裝置。Host 沒有遙測、使用分析或廣告，也不主動連上網際網路（自動更新服務只向 GitHub 查詢新版，見隱私權政策）。新裝置第一次連線，必須在電腦上按「允許」。

閱讀隱私權政策

運作方式

在電腦上安裝 Host 後，它會顯示配對頁（QR Code 與配對碼）。iPad 掃描或選擇「附近的電腦」配對，你在電腦上按「允許」，之後同一台 iPad 就不必再輸入配對碼。人在外面時，兩邊都登入同一個 Tailscale 網路即可連線。

下載與安裝

iPad／iPhone App

在 App Store 下載 Apobri。需要 iPadOS 或 iOS 17.0 以上。

App Store（即將上架）

Windows Host

在要被操作的 Windows 電腦上執行安裝程式（Windows 10 2004 以上、64 位元）。安裝只會跳出一次系統管理員授權，一次裝好 Host、通知區域圖示、背景服務（鎖定畫面、虛擬螢幕、自動更新）與防火牆規則（只對家用網路與 Tailscale 開放）。裝完會自動啟動，並開啟顯示 QR Code 的配對頁，用 iPad／iPhone 的 Apobri 掃描即可配對。

下載 Windows 安裝程式

如果出現「Windows 已保護您的電腦」：安裝程式目前還沒有程式碼簽章，Microsoft Defender SmartScreen 會顯示這個藍色視窗。請按「其他資訊」，確認檔名是 Apobri-Setup-…exe，再按「仍要執行」。下載頁旁附有 SHA-256 檢查碼，可用 PowerShell 的 Get-FileHash 核對。

解除安裝：Windows「設定 → 應用程式 → 已安裝的應用程式 → Apobri → 解除安裝」，會移除服務、虛擬螢幕驅動與防火牆規則，並詢問是否保留已配對裝置等資料。

系統需求

Windows 電腦Windows 10 或 Windows 11。需要有硬體 H.264／HEVC 編碼的 GPU：Intel（QSV）、NVIDIA（NVENC）或 AMD（AMF）任一種（近年的筆電與桌機幾乎都有）。沒有硬體編碼器的電腦（例如部分虛擬機）無法傳送畫面。Host 的影像編碼使用 ffmpeg，詳見授權與第三方聲明。
iPad／iPhoneiPadOS 17.0 或 iOS 17.0 以上。第一次連線時需允許「區域網路」權限。
網路iPad 與電腦在同一個區域網路，或兩邊都安裝並登入 Tailscale。不支援經由網際網路的其他連線方式（沒有 STUN／TURN）。

Apobri：用 iPad 或 iPhone 操作 Windows 電腦。不蒐集資料，不經雲端。
