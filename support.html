支援

遇到問題時，先看快速上手的問題排除與下方常見問題；仍無法解決，請附上診斷包寄給我們。

聯絡我們

Email：apobri.support@icloud.com

回信時請說明：電腦的 Windows 版本、iPad 型號與 iPadOS 版本、你做了什麼、看到什麼，以及診斷包（見下）。

常見問題

需要註冊帳號嗎？

不需要。Apobri 沒有帳號系統。

可以在外面用嗎？

可以。電腦和 iPhone／iPad 無法直接連線時，Apobri 可能經 Cloudflare 的轉接服務與 STUN（必要時 TURN 中繼）建立連線，它們看不到你的畫面與內容；但有些網路限制太嚴，不保證都連得上。最穩定的做法是 Tailscale：電腦與 iPhone／iPad 都安裝 Tailscale 並登入同一個帳號，步驟見快速上手：在外面也能連。Tailscale 不隨附於 Apobri，需自行安裝，並適用 Tailscale 自己的條款與隱私政策。

App 顯示「經由中繼」或「改用行動網路」是什麼意思？

電腦和 iPhone／iPad 之間沒辦法走直通的路時，資料會經過中途的伺服器繞一段（中繼）。繞遠路比較慢（常見多 60–150 ms），但畫面的清晰度與流暢度不變，照樣可以操作。

你不需要做任何設定。Apobri 會自己試好幾條路——Tailscale、Apobri 自己直通網際網路的路——哪條快就用哪條；連線中找到更快的路，也會自動換過去。

如果目前的 Wi‑Fi 怎麼試都只能繞遠路（有些公司、學校、飯店或店家的 Wi‑Fi 會擋掉直通的連線），而你的 iPhone／iPad 有行動網路，App 會問你要不要「改用行動網路」：按一下就換過去，會用到行動數據。不想換就不用理它，連線照樣能用。

為什麼要按「允許」成為信任裝置？

新裝置只要有電腦上的配對碼或 QR Code 就能連線，沒有配對碼的人連不進來。按「允許」是額外一步：這台裝置會成為信任裝置，金鑰加密存在電腦上，之後不必再輸入配對碼，分享選單與剪貼簿捷徑也能在背景使用。為了安全，只有正在操作這台電腦的那條連線能核准，60 秒內有效，整台電腦每小時最多 3 次，電腦鎖定或有人在電腦前時不能核准。

有聲音嗎？

有，但還很新、尚未在真的 iPad 上驗證：Host 會把 Windows 的系統聲音以 Opus 傳到 iPad，只在 WebRTC 傳輸時有效（WebSocket／HEVC 傳輸沒有聲音）。只有在 iPad 已連線且「聲音」開關開著時才會擷取。手機確認正在播放時，電腦本身會暫時靜音（避免兩邊同時出聲）；斷線、關掉聲音或重新啟動後會自動還原。想讓電腦繼續出聲，可在 config.json 設 "AudioMutePcWhileConnected": false。延遲與音畫同步還沒有實測。

支援哪些裝置？

用戶端是 iPad 與 iPhone（iPadOS／iOS 17.0 以上）；被操作端是 Windows 10／11 電腦。目前沒有 Mac、Android 或 Linux 版。

如何撤銷一台裝置？

在電腦工作列的 Apobri 圖示選「已配對的裝置」移除；或用命令列 AppleBridge.Host.exe --devices 列出、AppleBridge.Host.exe --revoke <編號開頭> 撤銷單一裝置，--revoke all 撤銷全部。已連線的工作階段會立刻中斷。

怎麼關閉「附近的電腦」廣播？

在 %APPDATA%\AppleBridge\config.json 加入 "Discovery": false 後重新啟動 Host。之後 iPad 需用 QR Code 或手動輸入位址配對。

為什麼程式檔案和資料夾叫 AppleBridge？

Apobri 的前身名稱是 AppleBridge，Host 的程式檔名與資料夾（例如 %APPDATA%\AppleBridge）目前仍沿用舊稱。

診斷包：產生與回報

診斷包是一個 zip，把排查問題需要的資訊整理在一起。它由電腦上的腳本產生，不會上傳任何東西，也不需要系統管理員權限；要不要寄出、寄給誰由你決定。

怎麼產生

  1. 開始功能表 > Apobri 資料夾 > 「Collect Apobri diagnostics」。（或在 Host 安裝資料夾的 scripts 資料夾執行 collect-diagnostics.ps1。）
  2. 完成後檔案管理員會開啟，檔案位於 文件\Apobri-diagnostics\apobri-diagnostics-<時間>.zip。
  3. 把 zip 附在 Email 寄給我們。寄出前建議先打開看看。

包含什麼

  • summary.txt：Host 版本與路徑、Windows 版本與語言、記憶體、顯示卡與驅動、.NET 版本、ffmpeg 版本與可用的硬體編碼器、工作排程與防火牆規則狀態、哪些程式在監聽 Host 的連接埠、是否安裝 Tailscale、網路介面卡、config.json 的設定（已移除配對碼與 Inbox Token）、已配對裝置的名稱／平台／最後連線時間。
  • host.log.tail.txt、host.err.log.tail.txt：記錄檔最後 2000 行（已遮蔽）。
  • capabilities.json：Host 對這台電腦的能力探測結果（編碼器、顯示卡、顯示模式、實測吞吐量）。
  • negotiate.recent.txt：最近幾次連線被給予什麼畫質，以及原因。
  • README-redaction.txt：遮蔽了哪些東西的統計。

不包含（已遮蔽或根本不讀取）

  • 配對碼與 Inbox Token、裝置金鑰；devices.json 完全不會被讀取。
  • 長十六進位字串（金鑰或權杖）、token=／key=／code= 之類的值、網址中的密碼參數、base64 內容。
  • 你的 Windows 使用者名稱與電腦名稱（路徑中的會被遮蔽）。
  • 螢幕畫面（Host 從不把畫面寫入磁碟）。
請注意：預設會保留IP 位址（排查區網或 Tailscale 問題需要）；若不想提供，可在執行腳本時加上 -RedactIps，IP 會被遮成 a.b.x.x。你自己取的裝置名稱（例如「小明的 iPad」）也會保留，寄出前請看一下。腳本若發現任何已知機密值在遮蔽後仍然存在，會中止而不產生 zip。

已知限制

我們寧可事先講清楚。以下是目前版本的限制：

  • 尚未有完整的實機驗證。開發主要在 Windows 上進行；iPad 原生 App 與真實網路環境下的表現還在驗證中，所以本站不提供效能數字。
  • 一次串流一個螢幕。Host 會列出接上的螢幕，可選擇要串流哪一個；不能同時看多個螢幕。
  • 延伸螢幕要自己開。預設 iPad 顯示的是電腦既有螢幕的內容；要讓 iPad 成為 Windows 多出來的螢幕，在 App 設定的「第二螢幕」選「延伸」（只有 iPad，電腦端 Host 也要是支援這項功能的版本）。
  • 聲音尚未實機驗證，且只有 WebRTC 傳輸有。Windows 系統聲音會以 Opus 傳到 iPad，但還沒有在真的 iPad 上聽過；延遲與音畫同步未測，WebSocket／HEVC 傳輸沒有聲音。
  • Ctrl+Alt+Del 無法從 iPad 送出。鎖定畫面、登入畫面、UAC 提示等「安全桌面」，Windows 不允許擷取與輸入，Apobri 只能顯示「電腦已鎖定」之類的說明，需在電腦上操作。
  • 剪貼簿可同步文字、圖片與檔案，但大小有上限（例如圖片約 16 MB），也不支援整個資料夾。
  • 舊版 App 與網頁版仍用明文 HTTP 建立連線。新版 iPad／iPhone App 的「信令」（建立連線的握手）走 TLS（wss，連接埠 8766），並釘選電腦憑證的指紋。舊版 App 與網頁版（PWA）仍使用未加密的 HTTP 連接埠（預設 8765），同一個網路上的其他人理論上可以看到這段握手（含以配對碼登入時的挑戰回應）。在不信任的網路（公共 Wi-Fi、辦公室）上，請使用新版 App，或改用 Tailscale 連線。
  • 配對碼存在 config.json 為純文字（僅限目前 Windows 使用者讀取）。同一個 Windows 帳號下的其他程式可以讀到它。
  • 經網際網路連線不保證成功：無法直連時，可能經 Cloudflare 的轉接服務與 STUN（必要時 TURN 中繼）建立連線，但限制嚴格的網路可能連不上；遠端使用最穩定的是 Tailscale。
  • 喚醒（Wake-on-LAN）只在同一個區網有效，且尚未完整實機驗證，見快速上手。

Apobri：用 iPad 或 iPhone 操作 Windows 電腦。不蒐集資料，不需帳號。
